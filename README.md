## ✨ Основные возможности

### 🌊 Визуализация 3D данных
- **Загрузка облаков точек** из форматов: `.xyz`, `.txt`, `.csv`, `.pts`, `.dat`
- **Интерактивная 3D-визуализация** с использованием OpenGL
- **Два режима отображения:**
  - 🔵 Точки (Point Cloud)
  - 🔺 Триангуляция Делоне (TIN - Triangulated Irregular Network)
- **27 цветовых палитр** для отображения высот с плавными градиентами
- **Настройка отображения:**
  - Размер точек (1-20)
  - Прозрачность (0-100%)
  - Вертикальный масштаб (1x-20x, только целые числа)
- **Работа с несколькими поверхностями** одновременно

### 📊 Профили сечений
- **Интерактивное создание профилей** - два клика мышью на плане
- **Визуализация сечения в 3D:**
  - Красная рамка границ сечения
  - Голубая полупрозрачная заливка (curtain)
  - Динамическая синхронизация с окном профиля
- **Окно профиля:**
  - Отображение профилей нескольких поверхностей одновременно
  - Zoom и pan с мгновенным обновлением рамки в 3D
  - Настраиваемые цвета для каждой поверхности
  - Сетка с координатами
- **Управление сечением клавишами:**
  - `←` `→` - смещение вдоль линии
  - `↑` `↓` - смещение перпендикулярно линии
  - `Page Up` `Page Down` - поворот сечения
  - `Home` - сброс к исходному положению
- **Экспорт профилей:**
  - В формат **DXF** (AutoCAD)
  - С сеткой координат и подписями
  - Настраиваемые параметры экспорта

### 🛤️ Работа с трассами
- **Загрузка трасс** из текстовых файлов (формат: X, Y на каждой строке)
- **Автоматический расчет:**
  - Длина трассы
  - Пикетаж с заданным шагом
  - Координаты пикетов
- **Настройки трассы:**
  - Референсная точка (начало отсчета)
  - Шаг пикетажа (метры)
  - Цвет отображения
  - Видимость пикетных меток
- **Визуализация в 3D:**
  - Линия трассы с учетом рельефа
  - Подписи пикетов (PK 0, PK 100, PK 200...)
  - Вертикальные маркеры на каждом пикете
- **Редактор трассы** - удобный диалог для настройки параметров

### 📐 Импорт DXF
- **Импорт 3D объектов** из файлов AutoCAD DXF
- **Поддерживаемые примитивы:**
  - `3DFACE` - 3D грани
  - `LINE` - линии
  - `LWPOLYLINE` - полилинии
  - `POLYLINE` - полилинии с высотой
- **Автоматическое извлечение** Z-координат
- **Отображение в 3D** вместе с поверхностями

### 💾 Проекты
- **Сохранение проектов** в формате `.xdv` (XYZ Data Viewer)
- **Сохраняется всё:**
  - Все загруженные поверхности
  - Пути к исходным файлам
  - Настройки отображения (палитры, прозрачность, масштаб)
  - Трассы с настройками
  - Импортированные DXF
  - Положение камеры
  - Состояние профилей
- **Автосохранение** - автоматическое сохранение при изменениях
- **Обработка отсутствующих файлов** при открытии проекта

## 🎯 Быстрый старт

### 1. Загрузка данных
- **Файл** → **Открыть XYZ файл** (или `Ctrl+O`)
- Выберите файл с данными (`.xyz`, `.txt`, `.csv`, `.pts`, `.dat`)
- Дождитесь окончания загрузки (прогресс-бар внизу)

### 2. Настройка отображения
- В панели **свойств** (справа) измените:
  - **Палитру** - выберите из 27 доступных
  - **Режим** - Точки или Триангуляция
  - **Прозрачность** - для просвечивания
  - **Вертикальный масштаб** - для лучшей визуализации рельефа

### 3. Создание профиля
- Нажмите кнопку **"Профиль"** на панели инструментов
- Кликните **два раза** мышью на плане (начало и конец линии)
- Откроется окно с графиком профиля
- Используйте **zoom** (колесико) и **pan** (левая кнопка) для детального просмотра

### 4. Сохранение проекта
- **Файл** → **Сохранить проект** (`Ctrl+S`)
- Выберите место и имя файла (`.xdv`)
- Все настройки и объекты будут сохранены

## 📋 Поддерживаемые форматы данных

### Входные форматы

#### XYZ файлы
```
# Формат: X Y Z (разделители: пробел, табуляция или запятая)
100.00 200.00 10.50
100.50 200.00 10.55
101.00 200.00 10.60
...
```

**Поддерживаемые расширения:** `.xyz`, `.txt`, `.csv`, `.pts`, `.dat`

**Особенности:**
- Автоматическое определение разделителя
- Игнорирование заголовков и комментариев (строки начинающиеся с `#`)
- Поддержка различных форматов чисел (точка/запятая как десятичный разделитель)

#### Трассы
```
# Формат: X Y (по одной точке на строке)
1000.00 2000.00
1010.50 2005.30
1020.80 2010.50
...
```

**Требования:**
- Только координаты X и Y
- Точки должны идти последовательно вдоль трассы

#### DXF файлы
- Стандарт: AutoCAD DXF R12 и выше
- Примитивы: `3DFACE`, `LINE`, `LWPOLYLINE`, `POLYLINE`
- Координаты: 3D (X, Y, Z)

### Выходные форматы

#### Проекты
- **Формат:** `.xdv` (JSON-based)
- **Содержит:** Все настройки, пути к файлам, состояние проекта

#### Экспорт
- **Изображения:** PNG, JPEG, BMP
- **DXF:** Профили с координатной сеткой
- **XYZ:** Облака точек

## 🐛 Известные ограничения

### Текущая версия (0.1.81-beta)

1. **Precomputation режимы** - работают нестабильно, требуют доработки
2. **Размер файлов** - файлы >500MB могут загружаться медленно
3. **Производительность** - при >1 млн точек возможны лаги на слабом железе
4. **DXF импорт** - поддерживаются только базовые примитивы

### Планируется исправить

- Оптимизация работы с большими файлами
- Улучшение производительности триангуляции
- Расширение поддержки DXF примитивов
- Добавление новых форматов данных
